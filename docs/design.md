# DESIGN — 리포트 화면 디자인 원칙

> 문서 상태: v0.2 (2026-11-03) — 화면 재구성(1~4장 + 부록, Phase 8-B)에 맞춤. 1장에만 적용됨, 확인 후 2~4장·부록으로 넓힌다

## 0. 방향

**증권사 리서치 리포트처럼 차분하고 정돈된 느낌 + 깔끔한 웹 대시보드 느낌.**
맨 위는 대시보드처럼 한눈에 보이게, 그 아래는 리포트처럼 읽히게 한다. 꾸밈보다 정돈을 우선한다.

## 1. 화면 구조

| 영역 | 원칙 |
| --- | --- |
| 헤더 (맨 위) | 기업명(크게)과 기준 정보(업종·생성일·기준 사업연도·데이터 기준일·연결/별도)를 한 줄로. 카드 상자 없이 **아래에 굵은 선** 하나로 본문과 나눈다 |
| 핵심 지표 (대시보드) | 지표 카드 4개를 가로로. 카드는 **옅은 회색 배경**만(테두리·그림자 없음). 큰 숫자, 전년 대비, 신호등. 신호등은 **색과 글자를 같이** 쓴다(색만으로 뜻을 전하지 않음) |
| 본문 섹션 (리포트) | 상자 대신 **가는 구분선**으로 섹션을 나눈다. 섹션 제목에 **번호**를 붙인다(장.순서, 예: 1.1 기업 개요). 종합 한 줄 평가·핵심 지표 카드는 대시보드 영역이라 번호를 붙이지 않는다 |
| 한 줄 요약 | 섹션 제목 바로 아래. **이것만 세리프(명조) 글꼴**, 왼쪽 **세로선**을 둬서 애널리스트 코멘트처럼 보이게. 종합 한 줄 평가도 같은 모양 |
| 근거·출처·AI 표시 | "AI 작성/AI 추출", 근거, 출처는 **작은 회색 글씨**로 내용 아래에 둔다. 본문보다 눈에 띄지 않게 |
| 내 코멘트 | 섹션 맨 아래, 가는 점선 위. 지금 모양 유지 |

## 2. 글꼴

- 본문: 시스템 고딕 (Apple SD Gothic Neo, Malgun Gothic, Noto Sans KR)
- 한 줄 요약·종합 평가만: 명조 (`'Noto Serif KR', 'Nanum Myeongjo', AppleMyungjo, Batang, serif`). 웹 글꼴은 따로 내려받지 않고 설치된 글꼴을 쓴다
- 숫자: **자릿수가 맞는 숫자(`font-variant-numeric: tabular-nums`)**. 표 숫자는 **오른쪽 정렬**
- 숫자 표시 형식은 spec.md "숫자 표시 규칙"을 그대로 따른다(금액 카드 조 원·표 억 원, 비율 소수 첫째 자리 %, 음수는 마이너스 기호와 빨강, 자료 없음은 회색)

## 3. 색

| 쓰임 | 색 |
| --- | --- |
| 신호등 3색 | 양호 `--good` #1b873f · 주의 `--warn` #b7791f · 위험 `--bad` #c62828 (음수 표시도 `--bad` 계열) |
| 강조색 하나 | `--accent` #2456a6 — 링크, 버튼, 차트의 기본 막대 |
| 나머지 | 흑백·회색: 글자 `--text`, 보조 글자 `--sub`, 선 `--line`, 지표 카드 배경 옅은 회색 |

- **그림자·그라데이션은 쓰지 않는다.** 둥근 모서리는 작게(지표 카드만)
- 예외: 개발 중 "개발용 예시 응답" 표시(주황)는 실제 결과와 헷갈리지 않게 하려는 경고라 그대로 둔다. 경고 안내(노란 상자)도 그대로 둔다
- 차트 여러 계열 색(경쟁사 비교 등)은 차트 안에서만 쓰고, 분석 기업은 강조색 계열로 구분한다 (부록 적용 때 정리)

## 4. 표

- 세로선·배경색 없이 **가로선으로만** 구분한다: 표 위 굵은 선, 머리글 아래 가는 검은 선, 행 사이 아주 옅은 선
- 머리글은 작은 회색 글씨. 첫 열(항목 이름)은 왼쪽, 숫자 열은 오른쪽 정렬
- 분석 기업 행처럼 강조가 필요하면 배경 대신 글자 굵기로

## 5. 장별 적용 (화면 순서는 spec.md F4: 1~4장 + 부록)

| 장 | 적용 |
| --- | --- |
| 1장 회사 한눈에 | 헤더 굵은 선 → **종합 한 줄 평가**(명조 + 왼쪽 세로선, 번호 없음) → 핵심 지표 대시보드 카드(번호 없음) → 1.1 기업 개요 · 1.2 사업부문 비중·BCG · 1.3 업계 위치. 2026-11-03 적용, 8-B에서 순서만 새 구성으로 맞춤 (SWOT은 3장으로 옮겨 지금은 기본 카드 모양) |
| 2장 지금 회사의 이슈 | 1장 확인 후 같은 원칙으로. 네이버 검색결과는 약관상 앞뒤에 다른 내용을 붙이지 않으므로 2장 마지막의 독립 섹션으로 두고 모양만 맞춘다 |
| 3장 강점과 과제 | SWOT 4칸은 상자 대신 위 굵은 선(1장 초안의 SWOT 모양을 옮겨 옴). **과제 3개는 번호 섹션**(과제 1·2·3), 과제마다 근거·필요 역량. "분석 기반 제안"·공식 인재상 아님 안내는 맨 위 유지 |
| 4장 나와의 연결 | 직무별 기여는 **나란히 비교되는 표**(행 = 과제, 열 = FP&A·재무회계·자금·리서치, 8-B에서 표로 바꿈), 예상 면접 질문, 숫자 모음은 줄마다 출처를 작은 회색 글씨로 |
| 부록 A~E | 기본 접힘. 접힌 상태는 제목·한 줄 요약만 보이는 목차처럼 정돈하고, 펼친 내용은 같은 원칙(가로선 표, 작은 회색 출처) |

## 6. 바꾸지 않는 것

- 기능·데이터·계산·문구 내용. 디자인 작업은 배치와 모양만 바꾼다
- 숫자 표시 규칙, 신호등 판정 기준, "AI 작성" 표시 자체(위치·크기만 조정)
