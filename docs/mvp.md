# MVP 정의서 — 기업분석 리포트 툴 (가칭)

> 문서 상태: 초안 v0.3 (2026-11-02) — 4페이지(회사의 과제와 나의 기여)·주식시세·기업 개요 보강 반영
> 다음 단계: 이 문서를 확정한 뒤 `docs/prd.md` 작성

---

## 1. 어떤 서비스인가

기업명 하나를 입력하면 **공시·재무 데이터, 기사, 경제 지표**를 모아
**4페이지 분량의 기업분석 리포트**를 만들어 주고, 리포트를 **저장해 쌓아 두는** 서비스.

- 분석은 **Top-down 순서**로 진행한다: 거시 환경 → 산업 → 회사 사업 → 재무 → 가치평가 → 종합
- 어려운 수치·이슈에는 **주석**을 단다: 의미 / 왜 중요한가 / 근거(출처 링크)
- 차트와 표로 **보고 이해하기 쉽게** 만든다.

## 2. 누구를 위한 서비스인가

- **1차 사용자: 나** — 상경 직무(FP&A·재무회계·자금·리서치)에 지원하는 취업 준비생
- 불편한 점
  - 자기소개서를 쓸 때마다 회사 정보를 DART·기사·증권 리포트에서 따로 찾아야 해서 오래 걸린다.
  - 찾은 내용이 흩어져 있어 다음 지원이나 면접 때 다시 찾기 어렵다.
  - 재무 수치는 봐도 "그래서 이 회사가 어떤 상황인지" 한 번에 정리되지 않는다.
- 해결 방향
  - 기업을 입력하면 정해진 분석 틀에 맞춘 리포트가 나오고, 리포트가 쌓인다.

## 3. 이번 MVP의 목표

> **상장 일반기업 1곳을 입력하면, 4페이지 리포트가 만들어지고 저장되어 다시 열어볼 수 있다.**

성공 기준 (직접 써보고 확인)
- [ ] 기업 1곳 리포트 생성까지 걸리는 시간: 목표 N분 이내 (확인 필요)
- [ ] 리포트의 모든 수치가 원문(DART)과 일치한다
- [ ] 주석과 기사 요약에 출처 링크가 빠짐없이 붙어 있다
- [ ] 저장한 리포트를 목록에서 찾아 다시 열 수 있다

## 4. 분석 순서와 리포트 구성 (4페이지)

### 분석 순서

| 순서 | 도구 | 무엇을 보나 | 만드는 방식 |
| --- | --- | --- | --- |
| 1. 거시 환경 | PEST | 정책·경제(환율, 금리)·사회·기술 변화의 영향 | AI 초안 → 내가 검토 |
| 2. 산업 | 5 Forces, 산업 생명주기 | 경쟁 강도, 진입장벽, 성장 단계 | AI 초안 → 내가 검토 |
| 3. 회사 사업 | BCG 매트릭스, 시장 지위 | 사업부문별 성장성·비중 | 숫자는 코드, 해석은 AI |
| 4. 재무 | 5대 비율, 듀퐁 분석, 현금흐름 패턴 | 수익성·안정성·활동성·성장성, ROE 구조, 현금흐름 부호 | 코드로 계산, AI는 주석만 |
| 5. 가치평가 | PER, PBR, 시가총액, 주가 흐름 | 동종업계 대비 수준, 최근 1년 주가 흐름 비교 | 코드로 계산 (주가 데이터 출처는 SPEC에서 결정) |
| 6. 종합 | SWOT | 1~5단계 결과 요약 | AI 정리 → 내가 확정 |
| 7. 과제·기여 | 회사의 핵심 과제 3개, 필요한 역량, 직무별 기여 아이디어 | 1~6단계 결과에서 AI 초안 → 내가 검토 |

### 리포트 구성

**1페이지 — 한눈에 보기**
- 기업 개요: 업종, 주력 사업, 직원 수·평균 근속연수·평균 급여, 연구개발비와 매출 대비 비중
- 핵심 지표 카드 4개 (매출 성장률, 영업이익률, 부채비율, 영업현금흐름) + 전년 대비 화살표 + 신호등
- 종합 한 줄 평가 + SWOT
- 동종업계 안에서의 위치 한 줄
- 차트: 사업부문별 매출 비중

**2페이지 — 재무 건전성과 회계 이슈**
- 매출·영업이익 최근 5년 연간 추이 (막대 + 선)
- 5대 비율 추이, 듀퐁 분석 (ROE = 이익률 × 회전율 × 레버리지)
- 현금흐름 패턴 (영업·투자·재무) + 해석 주석
- 회계 이슈 체크리스트: 감사의견, 계속기업 불확실성, 정정공시, 특수관계자 거래
- 동종업계 비교표 (아래 5번)
- 주가 흐름 비교 선 차트: 분석 기업과 경쟁사의 최근 1년 주가 (1년 전 = 100 기준)

**3페이지 — 외부 환경과 관심사항**
- PEST, 5 Forces 요약
- 최근 기사 주제별 묶음 3개 (요약 + 출처 링크)
- 경제 환경 민감도: 수출 비중, 환율·금리 추이, "환율 10% 상승 시" 영향 방향
- 앞으로 지켜볼 점 / 이 회사에 대해 생각해볼 질문

**4페이지 — 회사의 과제와 나의 기여**
- 1~3페이지 분석(SWOT 약점·위협, 기사 주제, 신호등, 민감도, 현금흐름)에서 뽑은 **회사의 핵심 과제 3개**, 과제마다 근거가 된 섹션 표시
- 과제별로 필요한 역량 1줄, 상경 직무 4개(FP&A·재무회계·자금·리서치) 관점의 기여 아이디어 1줄씩
- "분석 기반 제안", "AI 작성" 표시 + "회사의 공식 인재상이 아닙니다" 안내. 자기소개서 문장은 쓰지 않는다

### 모든 섹션 공통

- **자동 한 줄 요약**: 각 섹션 맨 위에 "이 섹션의 결론" 한 줄
- **내 코멘트란**: 각 섹션 아래에 내가 직접 메모를 남기는 칸 (저장됨)

### 주석 형식 (핵심 수치마다 같은 틀)

```
부채비율 180% (전년 140%, ▲40%p)
- 의미: 자기 돈 100원당 빌린 돈 180원
- 왜 중요한가: 금리가 높은 시기 이자 부담 증가, 투자 여력 감소
- 근거: 2025 사업보고서 연결재무상태표 (DART 링크)
```

## 5. 동종업계 비교 (가볍게, 비교 가능한 수준)

- 비교 대상: 경쟁사 3~4곳 — 업종 코드로 후보를 추천하고, **최종 선택은 내가** 한다
- 비교 지표 7개: 매출 규모, 매출 성장률, 영업이익률, ROE, 부채비율, PER·PBR, 시가총액
- 표시 방식: 표 1장 (동종 평균 대비 ▲▼ + 순위) + 점 그래프 1개 (가로 성장률 × 세로 이익률) + 주가 흐름 선 차트 1개 (1년 전 = 100 기준)
- 한 줄 코멘트: "이익률은 업계 상위, 성장률은 평균 이하"처럼 위치만 짚는다

## 6. 저장하는 정보

| 항목 | 내용 |
| --- | --- |
| 기업 정보 | 기업명, 종목코드, DART 기업코드, 업종 |
| 리포트 | 생성일, 기준 사업연도, 섹션별 내용, 한 줄 요약 |
| 수치 | 계산에 쓴 재무 데이터와 비율 (나중에 다시 계산하지 않도록) |
| 출처 | 각 수치·주석·기사 요약의 원문 링크 |
| 비교 대상 | 선택한 경쟁사 목록 |
| 내 기록 | 섹션별 내 코멘트 |

## 7. 할 수 있는 일

- 기업명으로 검색해 리포트 생성
- 경쟁사 후보 확인 후 3~4곳 선택
- 리포트 보기 (4페이지, 차트·주석 포함)
- 섹션별 내 코멘트 작성·수정
- 리포트 저장, 목록 보기, 기업명으로 검색, 삭제

## 8. 만들 때 지킬 원칙

1. **숫자는 코드가 계산하고, AI는 설명만 쓴다.** (AI가 숫자를 만들지 않게)
2. **모든 수치·주석·요약에 출처를 붙인다.**
3. **예측이 아니라 시나리오·민감도로 쓴다.** ("환율이 오르면 이런 방향의 영향")
4. **데이터는 공식 API를 우선한다.** 기사 사이트 직접 크롤링은 하지 않는다.
5. API 키 등 비밀정보는 `.env`에서만 관리한다.

## 9. 이번 MVP에서 만들지 않는 것

- 금융회사(은행·증권·보험) 분석 — 재무제표 구조가 달라 별도 버전 필요
- 비상장기업 분석
- 업종 평균 기준의 신호등 (MVP는 전년 대비 기준)
- DCF 등 상세 밸류에이션
- 자기소개서 자동 작성 (이 도구는 판단을 돕는 도구. 4페이지도 분석 기반 제안일 뿐 자기소개서 문장은 쓰지 않는다)
- 52주 최고·최저 위치, 주가 변동성
- 리포트 자동 업데이트, 지난 리포트와의 변경점 비교
- PDF 내보내기
- 회원가입·로그인, 여러 사용자 간 리포트 공유
- 지원 메모·지원 현황 관리

## 10. 결정한 사항 (2026-11-02)

| 항목 | 결정 |
| --- | --- |
| 회원 기능 | 1인용, 로그인 없음 |
| 가치평가 | PER·PBR을 MVP에 포함 (주가 데이터 출처는 SPEC에서 결정) |
| 재무 데이터 기간 | 최근 5년, 연간만 |
| 지원 메모 | 저장하지 않음 (순수 기업분석 도구로 유지, 지원 관리는 기존 채용 트래커에서) |
| 4페이지 | 추가: 회사의 핵심 과제 3개 + 필요한 역량 + 직무별 기여 아이디어 (자기소개서 문장 제외) |
| 주식시세 활용 | 추가: 시가총액과 경쟁사 중 순위, 1년 주가 흐름 비교 선 차트 |
| 1페이지 기업 개요 | 추가: 직원 수·평균 근속연수·평균 급여, 연구개발비와 매출 대비 비중 |

## 11. 확인 필요 (남은 항목)

1. **데이터 출처**: OpenDART(재무·공시), 기사(뉴스 검색 API 후보), 환율·금리(한국은행 ECOS 후보), 주가(PER·PBR용) — 각 API의 사용 조건 확인 → SPEC 단계에서 결정
2. **성공 기준 시간**: 리포트 1건 생성 목표 시간
3. **실행·배포 방식**: 로그인이 없으므로 내 컴퓨터(로컬)에서만 쓸지, 배포한다면 접근을 어떻게 제한할지
4. **1년 주가 시계열 조회**: 키 발급 후 가능 여부·호출 한도 확인 — `docs/spec.md` 6장 4번 (나머지 v0.3 추가 항목은 spec.md 5장에서 결정함)
