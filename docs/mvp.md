# MVP 정의서 — 기업분석 리포트 툴 (가칭)

> 문서 상태: 초안 v0.5 (2026-11-03) — 방향 조정: 서술은 사용자가 올린 사업보고서 PDF(필수)·반기/3분기 PDF(선택)에서 원문 인용 검증과 함께, 재무 숫자는 DART API. 경쟁사 선택·비교 없음. "지원자가 알아야 할 것"·"주의해서 볼 것" 두 축의 1~5장 + 부록
> 이전: v0.4 (2026-11-03) 1~4장 + 부록, 숫자 모음. v0.3 (2026-11-02) 4페이지(회사의 과제와 나의 기여)·주식시세·기업 개요 보강
> 다음 단계: `docs/prd.md`·`docs/spec.md`·`docs/plan.md`에 같은 내용 반영

---

## 1. 어떤 서비스인가

**목적: 기업분석을 쉽게 해서 취업 준비생이 자기소개서를 빨리 쓰게 돕는다.**

기업을 고르고 그 회사의 **사업보고서 PDF**를 올리면, **DART 재무 숫자·공시, 사업보고서 원문, 경제 지표**를 모아
**1~5장 + 부록으로 된 기업분석 리포트**를 만들어 주고, 리포트를 **저장해 쌓아 두는** 서비스.

- 내용은 두 축으로 묶는다: **지원자가 알아야 할 것**(1~3장: 회사 한눈에, 실적과 변화, 회사가 힘쓰는 곳)과 **주의해서 볼 것**(4장 체크리스트). 5장은 나와의 연결
- 재무 숫자는 DART API에서 가져와 코드가 계산하고, 회사의 서술(사업의 내용·경영진단·위험·경쟁·연구개발)은 올린 PDF에서 **원문 인용**과 함께 요약한다

- 분석은 **Top-down 순서**로 진행한다: 거시 환경 → 산업 → 회사 사업 → 재무 → 가치평가 → 종합 (안쪽 구조)
- 화면은 **결론부터** 보여준다: 1~5장, Top-down 심화 분석은 부록(기본 접힘)
- 어려운 수치·이슈에는 **주석**을 단다: 의미 / 왜 중요한가 / 근거(출처 링크)
- 차트와 표로 **보고 이해하기 쉽게** 만든다.

## 2. 누구를 위한 서비스인가

- **1차 사용자: 나** — 상경 직무(FP&A·재무회계·자금·리서치)에 지원하는 취업 준비생
- 불편한 점
  - 자기소개서를 쓸 때마다 회사 정보를 DART·기사·증권 리포트에서 따로 찾아야 해서 오래 걸린다.
  - 찾은 내용이 흩어져 있어 다음 지원이나 면접 때 다시 찾기 어렵다.
  - 재무 수치는 봐도 "그래서 이 회사가 어떤 상황인지" 한 번에 정리되지 않는다.
- 해결 방향
  - 기업을 입력하면 정해진 분석 틀에 맞춘 리포트가 나오고, 리포트가 쌓인다.
  - 리포트를 자기소개서 항목 순서로 읽을 수 있고, 출처가 붙은 검증된 숫자를 바로 가져다 쓸 수 있다. (문장은 내가 쓴다)

## 3. 이번 MVP의 목표

> **상장 일반기업 1곳을 고르고 사업보고서 PDF를 올리면, 1~5장 + 부록 리포트가 만들어지고 저장되어 다시 열어볼 수 있다.**

성공 기준 (직접 써보고 확인)
- [ ] 기업 1곳 리포트 생성까지 걸리는 시간: 목표 N분 이내 (확인 필요)
- [ ] 리포트의 모든 수치가 원문(DART)과 일치한다
- [ ] 주석·요약에 출처 링크가 빠짐없이 붙어 있고, PDF 원문 인용이 표시된 쪽에 실제로 있다
- [ ] 저장한 리포트를 목록에서 찾아 다시 열 수 있다
- [ ] 1~5장만 읽고 회사를 이해하고, 주의해서 볼 점과 자기소개서 재료·출처가 붙은 숫자를 찾을 수 있다

## 4. 분석 순서와 리포트 구성 (1~5장 + 부록)

### 분석 순서

| 순서 | 도구 | 무엇을 보나 | 만드는 방식 |
| --- | --- | --- | --- |
| 1. 거시 환경 | PEST | 정책·경제(환율, 금리)·사회·기술 변화의 영향 | AI 초안 → 내가 검토 |
| 2. 산업 | 5 Forces, 산업 생명주기 | 경쟁 강도, 진입장벽, 성장 단계 | AI 초안 → 내가 검토 |
| 3. 회사 사업 | BCG 매트릭스, 회사가 밝힌 경쟁 현황·경영진단·연구개발·투자·위험 | 사업부문별 성장성·비중, 사업보고서 서술 | 숫자는 코드, 서술은 올린 PDF에서 AI 요약 + 원문 인용 검증 |
| 4. 재무 | 5대 비율, 듀퐁 분석, 현금흐름 패턴 | 수익성·안정성·활동성·성장성, ROE 구조, 현금흐름 부호 | 코드로 계산, AI는 주석만 |
| 5. 가치평가 | PER, PBR, 시가총액, 주가 흐름 | 분석 기업의 수준과 최근 1년 주가 흐름 (경쟁사 비교 없음) | 코드로 계산 |
| 6. 주의할 점 | 체크리스트 | 일회성 이익·현금흐름·부채·이자·의존도·위험·회계 이슈 | 판정은 코드, 위험은 원문 인용 |
| 7. 종합 | SWOT | 1~6단계 결과 요약 | AI 정리 → 내가 확정 |
| 8. 과제·기여 | 회사의 핵심 과제 3개, 필요한 역량, 직무별 기여 아이디어 | 1~7단계 결과에서 AI 초안 → 내가 검토 |

### 리포트 구성 (화면 순서, 2026-11-03 방향 조정)

**1장 — 회사 한눈에** (지원자가 알아야 할 것)
- 종합 한 줄 평가 (맨 위)
- 지표 카드 4개 (매출 성장률, 영업이익률, 부채비율, 영업현금흐름) + 전년 대비 화살표 + 신호등
- 주력 사업(업종, 사업 설명, 직원 수·평균 근속연수·평균 급여)과 매출 구성(부문별 비중, 해외 비중, BCG 해석)
- 업계 위치: 사업보고서에서 **회사가 직접 언급한 경쟁사 이름과 점유율 문장**(원문 인용, 쪽 번호). 경쟁사 데이터를 끌어와 비교하지 않는다

**2장 — 실적과 변화** (지원자가 알아야 할 것)
- 최근 실적: 최근 반기/3분기 누적 손익을 전년 같은 기간과 비교(전기 vs 당기)
- 연간 추이 요약: 5년 매출·영업이익률
- 회사 스스로의 진단: 사업보고서 "이사의 경영진단 및 분석의견" 요약 + 원문 인용

**3장 — 회사가 힘쓰는 곳** (지원자가 알아야 할 것)
- 연구개발(요약·인용·연구개발비 비중), 투자·신규 시설, 신사업, 최근 3개월 공시 주제

**4장 — 주의해서 볼 것** (체크리스트)
- 일회성 이익, 현금흐름, 부채·이자, 고객·제품 의존도, 회사가 밝힌 위험 요인, 회계 이슈
- 판정(이상 없음 / 확인 필요 / 확인 불가)은 코드가 정해진 기준으로 하고, "확인 필요"에는 항상 이유를 붙인다(예: "확인 필요: 한 사업에 집중됨(DRAM 77.1%)" — 집중도는 위험이 아니라 볼 점). 위험 요인은 판정 없이 회사의 원문을 인용한다

**5장 — 나와의 연결** (자기소개서·면접)
- SWOT, 회사 과제 3개와 필요한 역량, 직무별(FP&A·재무회계·자금·리서치) 기여 아이디어, 예상 면접 질문, 자기소개서에 쓸 숫자 모음
- "분석 기반 제안", "AI 작성" 표시 + "회사의 공식 인재상이 아닙니다" 안내. 자기소개서 문장은 쓰지 않는다

**부록 — 심화 분석** (기본 접힘, 섹션별 펼치기)
- A. 거시: 환율·금리 추이와 민감도, PEST
- B. 산업: 5 Forces
- C. 재무 상세: 5대 비율 추이, 듀퐁 분석
- D. 가치평가: **분석 기업만** PER·PBR·시가총액, 최근 1년 주가(1년 전 = 100)
- E. 네이버 기사 참고 목록 (AI에 넣지 않고 받은 그대로)

### 모든 섹션 공통

- **자동 한 줄 요약**: 각 섹션 맨 위에 "이 섹션의 결론" 한 줄
- **내 코멘트란**: 각 섹션 아래에 내가 직접 메모를 남기는 칸 (저장됨)

### 주석 형식 (핵심 수치마다 같은 틀)

```
부채비율 180% (전년 140%, ▲40%p)
- 의미: 자기 돈 100원당 빌린 돈 180원
- 왜 중요한가: 금리가 높은 시기 이자 부담 증가, 투자 여력 감소
- 근거: 2025 사업보고서 연결재무상태표 (DART 링크)
```

## 5. 경쟁사 (2026-11-03 방향 조정)

- 경쟁사 데이터를 끌어와 비교하지 않는다. 경쟁사 선택 단계도 없다
- 사업보고서의 경쟁 현황에서 **회사가 직접 언급한** 경쟁사 이름과 점유율 문장을 원문 인용 검증과 함께 1장 업계 위치에 표기만 한다 ("회사가 밝힌 내용이며 이 도구가 확인한 시장 자료가 아님")
- 예전에 만든 경쟁사 재무 수집·비교표·점 그래프·주가 비교는 화면에서 숨기고 코드는 지우지 않는다

## 7. 할 수 있는 일

- 기업명으로 검색해 리포트 생성
- 사업보고서 PDF(필수)·반기/3분기 PDF(선택) 올리기, 기업·보고서와 맞는지 확인받기
- 리포트 보기 (1~5장 + 부록, 차트·주석·원문 인용 포함, 부록은 섹션별 펼치기)
- 섹션별 내 코멘트 작성·수정
- 리포트 저장, 목록 보기, 기업명으로 검색, 삭제

## 8. 만들 때 지킬 원칙

1. **숫자는 코드가 계산하고, AI는 설명만 쓴다.** (AI가 숫자를 만들지 않게)
2. **모든 수치·주석·요약에 출처를 붙인다.**
3. **예측이 아니라 시나리오·민감도로 쓴다.** ("환율이 오르면 이런 방향의 영향")
4. **데이터는 공식 API를 우선한다.** 기사 사이트 직접 크롤링은 하지 않는다.
5. API 키 등 비밀정보는 `.env`에서만 관리한다.
6. **AI는 원문 인용 검증을 거친 해석만 쓴다.** PDF에서 뽑은 서술은 인용이 원문에 실제로 있는지 코드가 확인한다. 네이버 기사는 AI에 넣지 않는다.

## 9. 이번 MVP에서 만들지 않는 것

- 금융회사(은행·증권·보험) 분석 — 재무제표 구조가 달라 별도 버전 필요
- 비상장기업 분석
- 경쟁사 데이터 비교(재무·비교표·주가) — 화면에서 숨김, 코드 유지
- 스캔본 PDF 글자 인식(OCR)
- 업종 평균 기준의 신호등 (MVP는 전년 대비 기준)
- DCF 등 상세 밸류에이션
- 자기소개서 자동 작성 (이 도구는 자기소개서를 빨리 쓰도록 **재료**를 주는 도구. 5장도 분석 기반 제안과 검증된 숫자일 뿐 자기소개서 문장은 쓰지 않는다)
- 52주 최고·최저 위치, 주가 변동성
- 리포트 자동 업데이트, 지난 리포트와의 변경점 비교
- PDF 내보내기
- 회원가입·로그인, 여러 사용자 간 리포트 공유
- 지원 메모·지원 현황 관리

| 1페이지 기업 개요 | 추가: 직원 수·평균 근속연수·평균 급여, 연구개발비와 매출 대비 비중 |
| 목적·화면 구성 (2026-11-03) | 목적을 "기업분석을 쉽게 해서 자기소개서를 빨리 쓰게 돕기"로 재정의. "4페이지"를 **1~4장 + 부록**으로 바꿈(결론부터, Top-down은 부록·안쪽 구조로 유지). 위치와 묶음만 바꾸고 기능·데이터·AI 호출 수·기존 코멘트 키는 그대로. 새 코멘트 키는 3장 과제·4장 숫자 모음 두 개 |
| 방향 조정 (2026-11-03) | 서술은 올린 사업보고서 PDF(필수)·반기/3분기 PDF(선택)에서 원문 인용 검증과 함께, 재무 숫자는 DART API. 흐름은 기업 검색 → PDF 올리기 → 리포트 생성. 경쟁사 선택·비교 없음(회사가 밝힌 경쟁 현황만 인용, 기존 코드 유지). 1~5장(알아야 할 것 1~3장, 주의해서 볼 것 4장, 나와의 연결 5장) + 부록. 기존 코멘트는 새 위치로 옮겨 보존 |
| 숫자 모음 (2026-11-03) | 4장에 "자기소개서에 쓸 숫자 모음" 추가. 코드가 검증된 숫자만 골라 한 줄 사실 9줄(매출액·매출 성장률·영업이익률·최근 실적·부채비율·영업현금흐름·해외 매출 비중·연구개발비 비중·시가총액 순위) + 출처 링크 (AI 없음) |

## 11. 확인 필요 (남은 항목)

1. **데이터 출처**: OpenDART(재무·공시), 기사(뉴스 검색 API 후보), 환율·금리(한국은행 ECOS 후보), 주가(PER·PBR용) — 각 API의 사용 조건 확인 → SPEC 단계에서 결정
2. **성공 기준 시간**: 리포트 1건 생성 목표 시간
3. **실행·배포 방식**: 로그인이 없으므로 내 컴퓨터(로컬)에서만 쓸지, 배포한다면 접근을 어떻게 제한할지
4. **1년 주가 시계열 조회**: 키 발급 후 가능 여부·호출 한도 확인 — `docs/spec.md` 6장 4번 (나머지 v0.3 추가 항목은 spec.md 5장에서 결정함)
