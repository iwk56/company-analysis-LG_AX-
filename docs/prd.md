# PRD (제품 요구사항 정의서) — 기업분석 리포트 툴 (가칭)

> 문서 상태: 초안 v0.5 (2026-11-03) — 방향 조정: 서술 내용은 사용자가 올린 사업보고서(필수)·반기/3분기보고서(선택) PDF에서 원문 인용 검증과 함께, 재무 숫자는 DART API. 경쟁사 선택·비교 없음(회사가 밝힌 경쟁 현황만 인용). "지원자가 알아야 할 것"·"주의해서 볼 것" 두 축의 1~5장 + 부록

## 1. 한 줄 정의

**상장 일반기업 1곳을 고르고 그 회사의 사업보고서 PDF를 올리면, DART 재무 숫자와 사업보고서 원문을 바탕으로 "지원자가 알아야 할 것"과 "주의해서 볼 것"을 정리한 리포트(1~5장 + 부록)를 주석·차트·원문 인용과 함께 만들어 저장해, 취업 준비생이 기업분석을 쉽게 하고 자기소개서를 빨리 쓰도록 돕는 개인용 도구.**

- 1~3장은 지원자가 알아야 할 것(회사 한눈에 → 실적과 변화 → 회사가 힘쓰는 곳), 4장은 주의해서 볼 것(체크리스트), 5장은 나와의 연결(SWOT·과제·직무별 기여·면접 질문·숫자 모음), 부록에 심화 분석(거시 → 산업 → 재무 상세 → 가치평가 → 네이버 기사)을 접어 둔다
- 회사의 서술(사업의 내용·경영진단·위험·경쟁·연구개발)은 **원문 인용**으로 보여주고, AI 요약은 인용이 실제 원문에 있는지 코드가 확인한 것만 쓴다
- 자기소개서 문장은 쓰지 않는다. 문장의 **재료**(분석·근거·검증된 숫자)를 준다

## 2. 누가 사용하는가

- **사용자: 나 1명** — 상경 직무(FP&A·재무회계·자금·리서치)에 지원하는 취업 준비생
- 사용 상황
  - 자기소개서를 쓰기 전, 지원 회사를 빠르게 전체적으로 이해하고 항목(지원동기·입사 후 포부·직무 역량)별 재료를 찾고 싶을 때
  - 면접 전, 예전에 만든 리포트를 다시 열어 복습할 때
  - 회사가 스스로 밝힌 경쟁 현황·위험·투자 방향을 원문 그대로 확인하고 싶을 때

## 3. 왜 필요한가

| 지금의 불편 | 이 도구로 달라지는 점 |
| --- | --- |
| DART·기사·지표를 따로 찾느라 회사 하나에 몇 시간씩 걸림 | 기업명 입력 한 번으로 정해진 틀의 리포트가 나옴 |
| 재무 수치는 봐도 "그래서 어떤 상황인지" 정리가 안 됨 | 핵심 수치마다 의미·중요한 이유·근거 주석이 붙음 |
| 찾은 내용이 흩어져 다음에 다시 찾기 어려움 | 리포트가 저장되고 목록에서 다시 열 수 있음 |
| 분석은 했는데 자기소개서 항목에 무엇을 쓸지 다시 정리해야 함 | 1~5장이 "알아야 할 것 → 주의해서 볼 것 → 나와의 연결"로 묶여 있고, 출처가 붙은 숫자 모음이 있음 |
| 사업보고서가 길어 어디에 무엇이 있는지 찾기 어려움 | 경영진단·연구개발·투자·위험·경쟁 현황을 요약과 원문 인용(쪽 번호)으로 정리 |
| 숫자만 보고는 무엇을 조심해야 할지 모름 | 4장 체크리스트(일회성 이익·현금흐름·부채·의존도·위험·회계 이슈)를 코드 기준으로 판정 |

## 4. 무엇을 할 수 있는가 (기능 목록)

| ID | 기능 | 설명 |
| --- | --- | --- |
| F1 | 기업 검색·선택 | 기업명으로 검색하고 분석할 기업 1곳을 고른다 |
| F2 | 보고서 PDF 올리기 | 사업보고서 PDF(필수)·반기/3분기보고서 PDF(선택)를 올리고, 선택한 기업·보고서 종류·기간과 맞는지 확인받는다 (2026-11-03, 구 경쟁사 선택을 대신함) |
| F3 | 리포트 생성 | 데이터 수집 → 계산 → 해석 순서로 리포트를 만들고, 진행 상황을 보여준다 |
| F4 | 리포트 보기 | 1~5장 + 부록(기본 접힘) 리포트를 차트·표·주석·원문 인용과 함께 본다. 4장 체크리스트, 5장 자기소개서에 쓸 숫자 모음(코드가 고른 검증된 숫자 + 출처) |
| F5 | 주석 보기 | 핵심 수치의 의미 / 왜 중요한가 / 근거(출처 링크)를 본다 |
| F6 | 내 코멘트 | 각 섹션 아래에 내 메모를 쓰고 고친다 |
| F7 | 리포트 목록 | 저장된 리포트를 목록으로 보고, 기업명으로 검색하고, 삭제한다. 같은 기업의 리포트가 여러 건이면 생성일로 구분한다 |

## 5. 사용 흐름

```
[홈] 기업명 검색 (+ 최근 리포트 목록)
   ↓ 기업 선택
[PDF 올리기] 올릴 보고서 안내 → 사업보고서 PDF(필수)·반기/3분기 PDF(선택) 올리기 → 칸마다 확인 결과
   ↓ 리포트 만들기
[생성 진행] 단계별 진행 표시 (PDF 읽기 → 재무 수집 → 공시 확인 → 기사 수집 → 계산 → 해석 작성)
   ↓ 완료 (자동 저장)
[리포트 보기] 1장 → 5장 (필요하면 부록 섹션을 펼쳐 근거 확인), 섹션별 코멘트 작성
   ↓
[리포트 목록] 다시 열기 / 검색 / 삭제
```

## 7. 리포트 내용 요구사항

내용 기준(2026-11-03 방향 조정): **"지원자가 알아야 할 것"(1~3장)**과 **"주의해서 볼 것"(4장)** 두 축. 재무 숫자는 DART API, 서술은 올린 PDF(원문 인용 검증). 경쟁사 데이터는 끌어오지 않는다

| 장 | 축 | 포함할 내용 |
| --- | --- | --- |
| 1. 회사 한눈에 | 알아야 할 것 (지원동기) | 종합 한 줄 평가, 지표 카드 4개(신호등·전년 대비), 주력 사업(업종·사업 설명·직원 현황)·매출 구성(부문 비중·해외 비중·BCG), 업계 위치(회사가 사업보고서에서 언급한 경쟁사 이름·점유율 문장, 원문 인용) |
| 2. 실적과 변화 | 알아야 할 것 (회사 이해) | 최근 실적(최근 반기/3분기 누적 vs 전년 같은 기간), 연간 추이 요약(5년 매출·영업이익률), 회사 스스로의 진단(이사의 경영진단 및 분석의견 요약 + 원문 인용) |
| 3. 회사가 힘쓰는 곳 | 알아야 할 것 (입사 후 포부의 재료) | 연구개발(요약·인용·연구개발비 비중), 투자·신규 시설, 신사업, 공시 주제 3개 |
| 4. 주의해서 볼 것 | 주의해서 볼 것 (체크리스트) | 일회성 이익, 현금흐름, 부채·이자, 고객·제품 의존도, 회사가 밝힌 위험 요인, 회계 이슈. 항목마다 이상 없음 / 확인 필요 / 확인 불가를 코드가 판정하고 **이유를 함께** 보여줌(예: "확인 필요: 한 사업에 집중됨(DRAM 77.1%)" — 집중도는 위험이 아님). 위험 요인은 판정 없이 인용 |
| 5. 나와의 연결 | 자기소개서·면접 | SWOT, 회사 과제 3개와 필요한 역량, 직무별 기여(FP&A·재무회계·자금·리서치), 예상 면접 질문, 자기소개서에 쓸 숫자 모음 |
| 부록. 심화 분석 | (근거) | 기본 접힘. A 거시(환율·금리·민감도, PEST) → B 산업(5 Forces) → C 재무 상세(5대 비율, 듀퐁) → D 가치평가(분석 기업만 PER·PBR·시가총액·1년 주가) → E 네이버 기사 참고 목록(AI에 넣지 않음) |

자기소개서에 쓸 숫자 모음 (5장)
- 이미 계산·검증된 숫자만 **코드가 골라** 한 줄 사실로 만든다. AI가 숫자를 새로 만들지 않고, AI 호출도 늘지 않는다
- 줄마다 출처 링크. 값이 없는 항목은 줄을 넣지 않는다. 항목 목록은 `docs/spec.md` 3장 (경쟁사 비교를 없애며 "시가총액 순위"는 "시가총액"으로)

원문 인용 (새 섹션)
- 업계 위치·경영진단·연구개발·투자·신사업·위험 요인·주요 고객은 AI가 요약과 함께 PDF 원문 인용을 돌려주고, 코드가 인용이 원문에 있는지 확인해 쪽 번호를 붙인다. 원문에 없는 인용과 인용이 없는 항목은 버린다

공통
- 모든 섹션 맨 위에 **자동 한 줄 요약**, 맨 아래에 **내 코멘트란**
- 핵심 수치마다 **주석**: 의미 / 왜 중요한가 / 근거(출처 링크)
- AI가 쓴 해석(PEST, 5 Forces, SWOT, 공시 주제 요약, 주석, 과제·기여 제안, 예상 면접 질문, PDF 서술 요약)에는 **"AI 작성" 표시**를 붙여 내가 검토할 부분임을 구분한다
- 리포트 상단에 **데이터 기준일**과 **기준 사업연도**를 표시한다

## 8. 품질 요구사항 (반드시 지킬 것)

1. **정확성**: 리포트의 모든 재무 수치는 원문(DART)과 일치해야 한다. 숫자는 코드가 계산하고 AI는 숫자를 만들지 않는다.
2. **출처**: 모든 수치·주석·요약에 원문 링크가 있어야 한다. PDF에서 뽑은 서술에는 원문 인용과 쪽 번호가 있어야 한다.
3. **표현**: 미래는 예측하지 않고 시나리오·민감도로 쓴다. ("환율이 오르면 이런 방향의 영향")
4. **이해하기 쉬움**: 전문 용어는 주석에서 쉬운 말로 풀어 쓴다.
5. **보안**: API 키는 `.env`에서만 관리하고 코드·문서·Git에 넣지 않는다.
6. **원문 인용 검증**: AI가 PDF 서술을 요약할 때 돌려준 인용이 원문에 없으면 그 항목을 보여주지 않는다. 회사가 밝힌 내용(경쟁 현황·위험·경영진단)은 이 도구의 평가와 구분해 표시한다.

## 9. 예외 상황에서의 동작

| 상황 | 동작 |
| --- | --- |
| 금융회사(은행·증권·보험)를 고른 경우 | "현재 버전은 일반기업만 분석합니다" 안내, 생성하지 않음 |
| 비상장기업·검색 결과 없음 | 검색 결과 없음 안내 |
| 상장 5년 미만이라 데이터가 부족한 경우 | 있는 연도만으로 만들고, 부족한 기간을 표시 |
| 관련 기사가 없는 경우 | 해당 섹션에 "최근 기사 없음" 표시, 나머지는 정상 생성 |
| 외부 데이터 연결 실패 | 실패한 단계를 알려주고 다시 시도할 수 있게 함 |
| 올린 PDF가 다른 회사·다른 보고서·다른 연도 | 그 칸을 거절하고 이유를 보여줌 ("이 PDF는 2024 사업보고서입니다. 2025 사업보고서를 올려 주세요") |
| 글자를 읽을 수 없는 PDF(스캔본) | 거절, DART 공시뷰어에서 받은 PDF를 올리라고 안내 (OCR 없음) |
| 사업보고서 PDF를 올리지 않음 | 리포트를 만들 수 없음 (반기/3분기는 선택) |
| PDF에서 목차 항목을 찾지 못함 | 리포트는 만들고 해당 섹션에 "사업보고서에서 이 항목을 찾지 못했습니다" |

## 10. 사용 환경

- **기기**: PC 웹 브라우저 (모바일 화면은 고려하지 않음)
- **실행**: 내 컴퓨터(로컬)에서만 실행
- **사용자 수**: 1명, 로그인 없음
- **공개 범위**: 리포트는 나만 본다. 공개·공유 기능 없음

## 11. 성공 기준

- 기업 1곳 리포트를 처음부터 저장까지 막힘 없이 만들 수 있다
- 리포트 수치를 DART 원문과 대조했을 때 모두 일치하고, 원문 인용이 표시된 쪽에 실제로 있다
- 출처 링크가 빠진 주석·요약이 없다
- 저장한 리포트를 목록에서 찾아 다시 열 수 있다
- (직접 써보고 측정) 리포트 1건으로 기업 이해에 드는 시간이 이전보다 줄었다
- (직접 써보고 확인) 부록을 펼치지 않고 1~5장만 읽어도 회사를 이해하고, 주의해서 볼 점과 자기소개서 재료·출처가 붙은 숫자를 찾을 수 있다

## 12. 이번에 만들지 않는 것

- 금융회사·비상장기업 분석
- 경쟁사 재무 수집·비교표·점 그래프·경쟁사 주가 비교 (2026-11-03부터 화면에서 숨김, 코드는 유지)
- 스캔본 PDF 글자 인식(OCR), PDF 원본 파일 보관(읽은 텍스트만 저장)

### 결정한 사항 (2026-11-03)

| 항목 | 결정 |
| --- | --- |
| 리포트 목적 | 기업분석을 쉽게 해서 취업 준비생이 자기소개서를 빨리 쓰게 돕는 것 |
| 화면 구성 | "4페이지"를 **1~4장 + 부록**으로 바꿈. 1~4장은 결론부터(자기소개서·면접 항목 순서), 부록은 Top-down 심화 분석(기본 접힘). 위치와 묶음만 바꾸고 기능·데이터·AI 호출 수·기존 코멘트 키는 그대로. 새 코멘트 키는 3장 과제·4장 숫자 모음 두 개 |
