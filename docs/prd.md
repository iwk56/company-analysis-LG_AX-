# PRD (제품 요구사항 정의서) — 기업분석 리포트 툴 (가칭)

> 문서 상태: 초안 v0.3 (2026-11-02) — 4페이지·주식시세·기업 개요 보강 반영
> 바탕 문서: `docs/mvp.md` v0.3
> 다음 단계: 이 문서를 확정한 뒤 `docs/spec.md` 작성

---

## 1. 한 줄 정의

**상장 일반기업 1곳을 입력하면, Top-down 순서로 분석한 4페이지 리포트를 주석·차트와 함께 만들어 저장해 주는 개인용 기업분석 도구.**

## 2. 누가 사용하는가

- **사용자: 나 1명** — 상경 직무(FP&A·재무회계·자금·리서치)에 지원하는 취업 준비생
- 사용 상황
  - 자기소개서를 쓰기 전, 지원 회사를 빠르게 전체적으로 이해하고 싶을 때
  - 면접 전, 예전에 만든 리포트를 다시 열어 복습할 때
  - 같은 업종의 여러 회사에 지원할 때, 회사 간 차이를 보고 싶을 때

## 3. 왜 필요한가

| 지금의 불편 | 이 도구로 달라지는 점 |
| --- | --- |
| DART·기사·지표를 따로 찾느라 회사 하나에 몇 시간씩 걸림 | 기업명 입력 한 번으로 정해진 틀의 리포트가 나옴 |
| 재무 수치는 봐도 "그래서 어떤 상황인지" 정리가 안 됨 | 핵심 수치마다 의미·중요한 이유·근거 주석이 붙음 |
| 찾은 내용이 흩어져 다음에 다시 찾기 어려움 | 리포트가 저장되고 목록에서 다시 열 수 있음 |
| 경쟁사와 비교하려면 또 따로 찾아야 함 | 경쟁사 1~4곳과의 비교표·차트가 리포트에 포함됨 |

## 4. 무엇을 할 수 있는가 (기능 목록)

| ID | 기능 | 설명 |
| --- | --- | --- |
| F1 | 기업 검색·선택 | 기업명으로 검색하고 분석할 기업 1곳을 고른다 |
| F2 | 경쟁사 선택 | 같은 업종 후보를 추천받고, 1~4곳을 고르거나 직접 추가한다 |
| F3 | 리포트 생성 | 데이터 수집 → 계산 → 해석 순서로 리포트를 만들고, 진행 상황을 보여준다 |
| F4 | 리포트 보기 | 4페이지 리포트를 차트·표·주석과 함께 본다 |
| F5 | 주석 보기 | 핵심 수치의 의미 / 왜 중요한가 / 근거(출처 링크)를 본다 |
| F6 | 내 코멘트 | 각 섹션 아래에 내 메모를 쓰고 고친다 |
| F7 | 리포트 목록 | 저장된 리포트를 목록으로 보고, 기업명으로 검색하고, 삭제한다. 같은 기업의 리포트가 여러 건이면 생성일로 구분한다 |

## 5. 사용 흐름

```
[홈] 기업명 검색 (+ 최근 리포트 목록)
   ↓ 기업 선택
[경쟁사 선택] 추천 후보 확인 → 1~4곳 선택
   ↓ 리포트 만들기
[생성 진행] 단계별 진행 표시 (재무 수집 → 공시 확인 → 기사 수집 → 계산 → 해석 작성)
   ↓ 완료 (자동 저장)
[리포트 보기] 1페이지 → 2페이지 → 3페이지 → 4페이지, 섹션별 코멘트 작성
   ↓
[리포트 목록] 다시 열기 / 검색 / 삭제
```

## 6. 화면 목록

| 화면 | 주요 내용 |
| --- | --- |
| 홈 | 기업명 검색창, 최근 리포트 몇 개 |
| 경쟁사 선택 | 업종 기반 추천 후보, 선택·제외·직접 추가 |
| 생성 진행 | 단계별 진행 상태, 실패 시 어느 단계에서 실패했는지 |
| 리포트 보기 | 4페이지 리포트, 섹션별 한 줄 요약·주석·내 코멘트 |
| 리포트 목록 | 기업명, 생성일, 기준 사업연도, 검색·삭제 |

## 7. 리포트 내용 요구사항

분석 순서: 거시 환경 → 산업 → 회사 사업 → 재무 → 가치평가 → 종합 → 과제·기여

| 페이지 | 포함할 내용 |
| --- | --- |
| 1. 한눈에 보기 | 기업 개요(업종·주력 사업, 직원 수·평균 근속연수·평균 급여, 연구개발비와 매출 대비 비중), 핵심 지표 카드 4개(신호등·전년 대비), 종합 한 줄 평가, SWOT, 동종업계 내 위치 한 줄, 사업부문별 매출 비중 차트 |
| 2. 재무 건전성·회계 이슈 | 최근 실적 박스(맨 위, 최근 반기/3분기 연결 누적 손익을 전년 같은 기간과 비교: 매출액·영업이익·영업이익률·지배주주 순이익과 증감, 기간 표시), 최근 5년 매출·영업이익 추이, 5대 비율 추이, 듀퐁 분석, 현금흐름 패턴, 회계 이슈 체크리스트, 동종업계 비교표·점 그래프, PER·PBR·시가총액(경쟁사 중 순위), 주가 흐름 비교 선 차트(1년 전 = 100 기준) |
| 3. 외부 환경·관심사항 | PEST, 5 Forces 요약, 기사 주제별 묶음 3개, 환율·금리 민감도, 지켜볼 점·생각해볼 질문 |
| 4. 회사의 과제와 나의 기여 | 1~3페이지 분석에서 뽑은 회사의 핵심 과제 3개(근거 섹션 표시), 과제별 필요한 역량 1줄, 직무 4개(FP&A·재무회계·자금·리서치) 관점의 기여 아이디어 1줄씩. "분석 기반 제안"·"AI 작성" 표시, 회사의 공식 인재상이 아니라는 안내 |

공통
- 모든 섹션 맨 위에 **자동 한 줄 요약**, 맨 아래에 **내 코멘트란**
- 핵심 수치마다 **주석**: 의미 / 왜 중요한가 / 근거(출처 링크)
- AI가 쓴 해석(PEST, 5 Forces, SWOT, 기사 요약, 주석, 과제·기여 제안)에는 **"AI 작성" 표시**를 붙여 내가 검토할 부분임을 구분한다
- 리포트 상단에 **데이터 기준일**과 **기준 사업연도**를 표시한다

## 8. 품질 요구사항 (반드시 지킬 것)

1. **정확성**: 리포트의 모든 재무 수치는 원문(DART)과 일치해야 한다. 숫자는 코드가 계산하고 AI는 숫자를 만들지 않는다.
2. **출처**: 모든 수치·주석·기사 요약에 원문 링크가 있어야 한다.
3. **표현**: 미래는 예측하지 않고 시나리오·민감도로 쓴다. ("환율이 오르면 이런 방향의 영향")
4. **이해하기 쉬움**: 전문 용어는 주석에서 쉬운 말로 풀어 쓴다.
5. **보안**: API 키는 `.env`에서만 관리하고 코드·문서·Git에 넣지 않는다.

## 9. 예외 상황에서의 동작

| 상황 | 동작 |
| --- | --- |
| 금융회사(은행·증권·보험)를 고른 경우 | "현재 버전은 일반기업만 분석합니다" 안내, 생성하지 않음 |
| 비상장기업·검색 결과 없음 | 검색 결과 없음 안내 |
| 상장 5년 미만이라 데이터가 부족한 경우 | 있는 연도만으로 만들고, 부족한 기간을 표시 |
| 관련 기사가 없는 경우 | 해당 섹션에 "최근 기사 없음" 표시, 나머지는 정상 생성 |
| 외부 데이터 연결 실패 | 실패한 단계를 알려주고 다시 시도할 수 있게 함 |

## 10. 사용 환경

- **기기**: PC 웹 브라우저 (모바일 화면은 고려하지 않음)
- **실행**: 내 컴퓨터(로컬)에서만 실행
- **사용자 수**: 1명, 로그인 없음
- **공개 범위**: 리포트는 나만 본다. 공개·공유 기능 없음

## 11. 성공 기준

- 기업 1곳 리포트를 처음부터 저장까지 막힘 없이 만들 수 있다
- 리포트 수치를 DART 원문과 대조했을 때 모두 일치한다
- 출처 링크가 빠진 주석·요약이 없다
- 저장한 리포트를 목록에서 찾아 다시 열 수 있다
- (직접 써보고 측정) 리포트 1건으로 기업 이해에 드는 시간이 이전보다 줄었다

## 12. 이번에 만들지 않는 것

- 금융회사·비상장기업 분석
- 업종 평균 기준의 신호등 (MVP는 전년 대비 기준)
- DCF 등 상세 밸류에이션
- 자기소개서 자동 작성 (4페이지는 분석 기반 제안일 뿐 자기소개서 문장은 쓰지 않는다)
- 52주 최고·최저 위치, 주가 변동성
- 리포트 자동 업데이트, 이전 리포트와의 변경점 비교
- PDF 내보내기
- 회원가입·로그인, 공유
- 지원 메모·지원 현황 관리
- 모바일 화면

## 13. 결정한 사항 (2026-11-02)

| 항목 | 결정 |
| --- | --- |
| 같은 기업 재생성 | 새 리포트로 따로 저장 (이전 리포트와 내 코멘트 보존) |
| 주석 표시 | 수치를 누르면 펼쳐지는 방식 (기본 화면은 간결하게) |

| 4페이지 | 회사의 과제 3개 + 필요한 역량 + 직무별 기여 아이디어를 추가 (공식 인재상이 아님을 안내) |
| 주식시세 활용 | 시가총액과 경쟁사 중 순위, 1년 주가 흐름 비교 선 차트를 추가 |
| 1페이지 기업 개요 | 직원 수·평균 근속연수·평균 급여, 연구개발비와 매출 대비 비중을 추가 |

## 14. 아직 정하지 않은 것 (확인 필요 → SPEC에서 결정)

2. **데이터 출처**: 재무·공시, 기사, 환율·금리, 주가 각각의 API와 사용 조건
3. **1년 주가 시계열 조회**: 키 발급 후 가능 여부·호출 한도 확인 → `docs/spec.md` 6장 4번 (나머지 v0.3 추가 항목은 spec.md 5장에서 결정함)
