## 1. 한 줄 정의

**상장 일반기업 1곳을 입력하면, Top-down 순서로 분석한 결과를 결론부터 보여주는 리포트(1~4장 + 부록)를 주석·차트와 함께 만들어 저장해, 취업 준비생이 기업분석을 쉽게 하고 자기소개서를 빨리 쓰도록 돕는 개인용 도구.**

- 1~4장은 자기소개서·면접 항목 순서(지원동기 → 회사 이해·시사 → 입사 후 포부 → 직무 역량·면접)로 결론과 재료를 보여주고, 부록에 근거가 되는 심화 분석(거시 → 산업 → 재무 → 가치평가 → 경쟁사)을 접어 둔다
- 자기소개서 문장은 쓰지 않는다. 문장의 **재료**(분석·근거·검증된 숫자)를 준다

## 2. 누가 사용하는가

- **사용자: 나 1명** — 상경 직무(FP&A·재무회계·자금·리서치)에 지원하는 취업 준비생
- 사용 상황
  - 자기소개서를 쓰기 전, 지원 회사를 빠르게 전체적으로 이해하고 항목(지원동기·입사 후 포부·직무 역량)별 재료를 찾고 싶을 때
  - 면접 전, 예전에 만든 리포트를 다시 열어 복습할 때
  - 같은 업종의 여러 회사에 지원할 때, 회사 간 차이를 보고 싶을 때

## 3. 왜 필요한가

| 지금의 불편 | 이 도구로 달라지는 점 |
| --- | --- |
| DART·기사·지표를 따로 찾느라 회사 하나에 몇 시간씩 걸림 | 기업명 입력 한 번으로 정해진 틀의 리포트가 나옴 |
| 재무 수치는 봐도 "그래서 어떤 상황인지" 정리가 안 됨 | 핵심 수치마다 의미·중요한 이유·근거 주석이 붙음 |
| 찾은 내용이 흩어져 다음에 다시 찾기 어려움 | 리포트가 저장되고 목록에서 다시 열 수 있음 |
| 분석은 했는데 자기소개서 항목에 무엇을 쓸지 다시 정리해야 함 | 1~4장이 자기소개서 항목 순서로 묶여 있고, 출처가 붙은 숫자 모음이 있음 |
| 경쟁사와 비교하려면 또 따로 찾아야 함 | 경쟁사 1~4곳과의 비교표·차트가 리포트에 포함됨 |

## 4. 무엇을 할 수 있는가 (기능 목록)

| ID | 기능 | 설명 |
| --- | --- | --- |
| F1 | 기업 검색·선택 | 기업명으로 검색하고 분석할 기업 1곳을 고른다 |
| F2 | 경쟁사 선택 | 같은 업종 후보를 추천받고, 1~4곳을 고르거나 직접 추가한다 |
| F3 | 리포트 생성 | 데이터 수집 → 계산 → 해석 순서로 리포트를 만들고, 진행 상황을 보여준다 |
| F4 | 리포트 보기 | 1~4장 + 부록(기본 접힘) 리포트를 차트·표·주석과 함께 본다. 4장에 자기소개서에 쓸 숫자 모음(코드가 고른 검증된 숫자 + 출처) |
| F5 | 주석 보기 | 핵심 수치의 의미 / 왜 중요한가 / 근거(출처 링크)를 본다 |
| F6 | 내 코멘트 | 각 섹션 아래에 내 메모를 쓰고 고친다 |
| F7 | 리포트 목록 | 저장된 리포트를 목록으로 보고, 기업명으로 검색하고, 삭제한다. 같은 기업의 리포트가 여러 건이면 생성일로 구분한다 |

## 5. 사용 흐름

```
[홈] 기업명 검색 (+ 최근 리포트 목록)
   ↓ 기업 선택
[경쟁사 선택] 추천 후보 확인 → 1~4곳 선택
   ↓ 리포트 만들기
[생성 진행] 단계별 진행 표시 (재무 수집 → 공시 확인 → 기사 수집 → 계산 → 해석 작성)
   ↓ 완료 (자동 저장)
[리포트 보기] 1장 → 2장 → 3장 → 4장 (필요하면 부록 섹션을 펼쳐 근거 확인), 섹션별 코멘트 작성
   ↓
[리포트 목록] 다시 열기 / 검색 / 삭제
```

## 6. 화면 목록

| 화면 | 주요 내용 |
| --- | --- |
| 홈 | 기업명 검색창, 최근 리포트 몇 개 |
| 경쟁사 선택 | 업종 기반 추천 후보, 선택·제외·직접 추가 |
| 생성 진행 | 단계별 진행 상태, 실패 시 어느 단계에서 실패했는지 |
| 리포트 보기 | 1~4장 + 부록(기본 접힘, 섹션별 펼치기), 섹션별 한 줄 요약·주석·내 코멘트 |
| 리포트 목록 | 기업명, 생성일, 기준 사업연도, 검색·삭제 |

## 7. 리포트 내용 요구사항

분석 순서(안쪽 구조, 그대로 유지): 거시 환경 → 산업 → 회사 사업 → 재무 → 가치평가 → 종합 → 과제·기여
화면 순서(결론부터): 1~4장 → 부록. 위치와 묶음만 바꾸고 기능·데이터·AI 호출 수는 바꾸지 않는다

| 장 | 자기소개서·면접 항목 | 포함할 내용 |
| --- | --- | --- |
| 1. 회사 한눈에 | 지원동기 | 종합 한 줄 평가와 핵심 지표 카드 4개(신호등·전년 대비)를 맨 위에, 이어서 기업 개요(업종·주력 사업, 직원 수·평균 근속연수·평균 급여, 연구개발비와 매출 대비 비중), 사업부문별 매출 비중·BCG, 업계 위치(시가총액과 경쟁사 중 순위, 업계 내 위치 한 줄) |
| 2. 지금 회사의 이슈 | 회사 이해·시사 | 최근 실적 박스(최근 반기/3분기 연결 누적 손익을 전년 같은 기간과 비교: 매출액·영업이익·영업이익률·지배주주 순이익과 증감, 기간 표시), 공시 주제 묶음 3개, 네이버 기사 참고 목록(AI에 넣지 않음) |
| 3. 강점과 과제 | 입사 후 포부 | 근거가 붙은 SWOT, 회사의 핵심 과제 3개(근거 섹션 표시)와 과제별 필요한 역량 1줄 |
| 4. 나와의 연결 | 직무 역량·면접 | 직무 4개(FP&A·재무회계·자금·리서치) 관점의 과제별 기여 아이디어 1줄씩, 예상 면접 질문(지켜볼 점·생각해볼 질문 활용), 자기소개서에 쓸 숫자 모음 |
| 부록. 심화 분석 | (근거) | Top-down 순서, 기본 접힘·섹션별 펼치기. A 거시(PEST, 환율·금리, 환율 민감도) → B 산업(5 Forces) → C 재무(5년 매출·영업이익 추이, 5대 비율, 듀퐁, 현금흐름 패턴, 회계 이슈 체크리스트) → D 가치평가(PER·PBR·시가총액, 주가 흐름 비교 선 차트 1년 전 = 100) → E 경쟁사 비교표·점 그래프 |

자기소개서에 쓸 숫자 모음 (4장, 새 섹션)
- 이미 계산·검증된 숫자만 **코드가 골라** 한 줄 사실로 만든다(예: "2025년 영업이익률 48.6%", "해외 매출 비중 98.0%(AI 추출)"). AI가 숫자를 새로 만들지 않고, AI 호출도 늘지 않는다
- 줄마다 출처 링크. 값이 없는 항목은 줄을 넣지 않는다. 항목 목록은 `docs/spec.md` 3장

공통
- 모든 섹션 맨 위에 **자동 한 줄 요약**, 맨 아래에 **내 코멘트란**
- 핵심 수치마다 **주석**: 의미 / 왜 중요한가 / 근거(출처 링크)
- AI가 쓴 해석(PEST, 5 Forces, SWOT, 공시 주제 요약, 주석, 과제·기여 제안, 예상 면접 질문)에는 **"AI 작성" 표시**를 붙여 내가 검토할 부분임을 구분한다
- 리포트 상단에 **데이터 기준일**과 **기준 사업연도**를 표시한다

## 8. 품질 요구사항 (반드시 지킬 것)

1. **정확성**: 리포트의 모든 재무 수치는 원문(DART)과 일치해야 한다. 숫자는 코드가 계산하고 AI는 숫자를 만들지 않는다.
2. **출처**: 모든 수치·주석·기사 요약에 원문 링크가 있어야 한다.
3. **표현**: 미래는 예측하지 않고 시나리오·민감도로 쓴다. ("환율이 오르면 이런 방향의 영향")
4. **이해하기 쉬움**: 전문 용어는 주석에서 쉬운 말로 풀어 쓴다.
5. **보안**: API 키는 `.env`에서만 관리하고 코드·문서·Git에 넣지 않는다.

## 9. 예외 상황에서의 동작

| 상황 | 동작 |
| --- | --- |
| 금융회사(은행·증권·보험)를 고른 경우 | "현재 버전은 일반기업만 분석합니다" 안내, 생성하지 않음 |

| 관련 기사가 없는 경우 | 해당 섹션에 "최근 기사 없음" 표시, 나머지는 정상 생성 |
| 외부 데이터 연결 실패 | 실패한 단계를 알려주고 다시 시도할 수 있게 함 |

## 10. 사용 환경

- **기기**: PC 웹 브라우저 (모바일 화면은 고려하지 않음)
- **실행**: 내 컴퓨터(로컬)에서만 실행
- **사용자 수**: 1명, 로그인 없음
- **공개 범위**: 리포트는 나만 본다. 공개·공유 기능 없음

## 11. 성공 기준

- 기업 1곳 리포트를 처음부터 저장까지 막힘 없이 만들 수 있다
- 리포트 수치를 DART 원문과 대조했을 때 모두 일치한다
- 출처 링크가 빠진 주석·요약이 없다
- 저장한 리포트를 목록에서 찾아 다시 열 수 있다
- (직접 써보고 측정) 리포트 1건으로 기업 이해에 드는 시간이 이전보다 줄었다
- (직접 써보고 확인) 부록을 펼치지 않고 1~4장만 읽어도 자기소개서 항목(지원동기·입사 후 포부·직무 역량)별 재료와 출처가 붙은 숫자를 찾을 수 있다

## 12. 이번에 만들지 않는 것

- 금융회사·비상장기업 분석
- 업종 평균 기준의 신호등 (MVP는 전년 대비 기준)
- DCF 등 상세 밸류에이션
- 자기소개서 자동 작성 (목적은 자기소개서를 빨리 쓰게 돕는 것이지만, 3·4장은 분석 기반 제안과 재료일 뿐 자기소개서 문장은 쓰지 않는다)
- 52주 최고·최저 위치, 주가 변동성
- 리포트 자동 업데이트, 이전 리포트와의 변경점 비교
- PDF 내보내기
- 회원가입·로그인, 공유
- 지원 메모·지원 현황 관리
- 모바일 화면

| 항목 | 결정 |
| --- | --- |
| 리포트 목적 | 기업분석을 쉽게 해서 취업 준비생이 자기소개서를 빨리 쓰게 돕는 것 |
