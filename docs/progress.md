## Phase 2 진행 메모

- 시연 기업은 **SK하이닉스**, 비교 기업은 **삼성전자**로 정했다
- DART가 막혀 있는 동안 계산 모듈만 먼저 만듦 (`backend/app/calc/`: 비율·듀퐁·현금흐름 패턴·신호등). 입력은 표준 항목(`YearFinancials`)이고 DART 계정 이름 연결은 복구 후에 만든다. DART는 호출하지 않음
- spec.md 해석 확정(2026-11-02): 듀퐁은 순이익률·레버리지를 지배주주 기준으로 통일(곱=ROE), 주된 요인은 요소별 전년 대비 변화율(%)의 절댓값이 가장 큰 것, 신호등은 위험 조건(적자·부채비율 200% 초과)이 전년 대비 판정보다 우선하고 영업현금흐름 0·전년과 같음은 주의, 적자 연도의 비율은 음수 숫자로 표시(해당 없음은 분모 0·음수·자본잠식일 때만)
- 아직 안 한 것: DART 계정 이름 → 표준 항목 연결, 5개 연도 재무제표 수집, 시연 기업 DART 원문 대조, 연결/별도 구분
