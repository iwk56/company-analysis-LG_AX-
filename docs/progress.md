- 고친 문서: mvp.md v0.5, prd.md v0.5, spec.md v0.5(F2 PDF 올리기·확인 새로, F3 PDF 읽기 단계·"PDF에서 읽는 섹션" 표, F4 전면 재작성·대응표, 3장 "4장 체크리스트 판정"·이유 문장 틀, 4장 저장 "올린 PDF", 6장 확정 12개), plan.md v0.4(Phase 8-C·8-D·8-E 추가)
- **입력 방식**: 재무 숫자는 지금처럼 DART API. 서술(사업의 내용, 이사의 경영진단 및 분석의견, 위험, 경쟁 현황, 연구개발)은 사용자가 올린 **사업보고서 PDF(필수)·반기/3분기보고서 PDF(선택)**에서 뽑는다. 흐름: 기업 검색 → PDF 올리기 → 리포트 생성. 경쟁사 선택 단계 없음
- **5장 구성**: "지원자가 알아야 할 것" 1장 회사 한눈에(종합 한 줄 평가·지표 카드·주력 사업·매출 구성·업계 위치) · 2장 실적과 변화(최근 실적·연간 추이·회사 스스로의 진단) · 3장 회사가 힘쓰는 곳(연구개발·투자·신규 시설·신사업·공시 주제), "주의해서 볼 것" 4장 체크리스트(일회성 이익·현금흐름·부채·이자·고객·제품 의존도·회사가 밝힌 위험 요인·회계 이슈), 5장 나와의 연결(SWOT·회사 과제·직무별 기여·예상 면접 질문·숫자 모음), 부록 A 거시(민감도·PEST) · B 산업(5 Forces) · C 재무 상세(비율·듀퐁) · D 가치평가(분석 기업만) · E 네이버 기사
- **경쟁사는 표기만**: 사업보고서에서 회사가 직접 언급한 경쟁사 이름·점유율 문장을 원문 인용 검증과 함께 1장 업계 위치에 보여준다. 경쟁사 재무 수집·비교표·점 그래프·주가 비교는 화면에서 숨기고 코드는 지우지 않는다
- 원칙: 숫자는 코드, AI는 원문 인용 검증을 거친 해석만(인용이 PDF 텍스트에 없으면 버리고 쪽 번호를 붙임), 네이버 기사는 AI에 넣지 않음. **기존 코멘트 키 20개를 새 섹션에 1:1로 붙여 DB 이전 없이 보존**(`competitors` 코멘트는 1장 업계 위치에), 새 키 8개(`mda`·`rnd`·`investment`·`new_business`·`one_off`·`debt`·`dependence`·`risks`)

  2. 사업보고서 PDF 필수, DART 원문으로 자동 대체하지 않음. 반기/3분기는 선택

  4. PEST·민감도는 부록 A에 남김

  6. 숫자 모음 9번: 시가총액 순위 → 시가총액(분석 기업)

  8. 반기/3분기 PDF는 3장 "최근 보고서에서 바뀐 점" 보충에만(반기보고서에는 경영진단을 기재하지 않음)
