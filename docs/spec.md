## 0. 공통 규칙

1. **숫자는 코드가 계산한다.** AI에게는 계산이 끝난 숫자와 원문 자료만 넘기고, AI는 해석·요약·주석 문장만 쓴다.
2. **AI는 넘겨받은 자료 안에서만 쓴다.** 자료에 없는 사실·숫자를 만들지 않고, 근거가 없으면 "자료 없음"이라고 쓴다.
3. **출처를 붙인다.** 수치·주석·기사 요약마다 원문 링크(DART 공시 원문, 기사 URL, 한국은행 통계)를 저장하고 보여준다.
4. **AI가 쓴 부분은 "AI 작성" 표시**를 붙인다.
5. 숫자 표시는 아래 **"숫자 표시 규칙"** 하나로 통일한다. 금액은 카드 조 원·표 억 원, 비율은 소수점 첫째 자리 %. (예외: 평균 급여는 만 원)
6. 재무제표는 **연결재무제표를 우선**하고, 연결이 없으면 별도재무제표를 쓰며 어느 쪽인지 표시한다.
7. 기간은 **최근 5개 사업연도(연간, 사업보고서 기준)**.
8. **AI 호출은 코드 한 곳(모듈 하나)에 모은다.** 제공자는 `.env`의 `LLM_PROVIDER`(`openai` 또는 `anthropic`, 기본 `openai`)로 고르고, 제공자를 바꿔도 나머지 코드는 그대로 둔다.
9. **AI 사용량을 아낀다.** OpenAI 키는 부서 공유 키라 사용량 한도를 직접 걸 수 없을 수 있다. 개발 중 AI 호출 테스트는 **SK하이닉스 1곳으로만** 하고, **같은 리포트의 해석은 다시 만들지 않는다** (한 번 만들어 저장한 해석은 저장본을 그대로 쓰고, 리포트를 열 때는 AI를 호출하지 않는다. 실패한 단계의 [다시 시도]는 실패한 호출만 다시 보낸다).

### 숫자 표시 규칙 (화면 공통, 2026-11-02 추가)

화면의 모든 숫자는 프론트엔드의 변환 함수 한 곳(`frontend/src/format/`)을 거쳐 표시한다. 저장값은 바꾸지 않는다(금액은 DART 원문 그대로 원 단위 정수, 비율은 소수 0.123 = 12.3%).

| 대상 | 규칙 | 예시 |
| --- | --- | --- |
| 금액 (카드) | **조 원**, 소수 첫째 자리. 절댓값이 0.1조 원 미만이면 "0.0조"로 보이지 않도록 억 원(쉼표)으로 대신 표시 | 53.4조 원 |
| 금액 (표) | **억 원**, 정수, 천 단위 쉼표. 단위는 셀이 아니라 **표 제목에 표시** | 제목 "(단위: 억 원)", 셀 971,467 |
| 음수 | 앞에 **− 기호**(U+2212)를 붙이고 **빨간색**. 반올림해서 0이 되면 음수로 표시하지 않음 | −77,303 |
| 비율 | **소수 첫째 자리 %** | 28.9% |
| 증감 | 매출·이익 등의 증감률은 **+/− 부호가 붙은 %**, 비율끼리의 차이(예: 영업이익률 변화)는 **%p** | +230.8%, +32.6%p |
| 환율·기준금리 | 환율은 **소수 첫째 자리 + 원**, 기준금리는 0.25%p 단위로 움직이므로 **소수 둘째 자리 %** (2.75%가 2.8%로 보이지 않게) | 1,337.2원, 2.75% |
| 배수 | 회전율·이자보상배율·재무레버리지는 %가 아니라 **배**, 소수 첫째 자리 | 3.8배 |
| 표 안의 숫자 | **오른쪽 정렬**, 숫자 폭이 같은 글꼴(tabular-nums) | |
| 신호등 | **초록·노랑·빨강 색 + "양호·주의·위험" 글자를 함께** 표시 (색만으로 구분하지 않음). 판정 이유는 마우스를 올리거나 옆 작은 글씨로 | ● 양호 |
| 해당 없음 | 계산할 수 없는 값은 **이유와 함께** 표시, 회색 글자 | 해당 없음(적자), 해당 없음(전기 자료 없음) |
| 자료 없음 | 수집하지 못한 값(이유를 따로 받지 못한 경우) | 자료 없음 |
| 평균 대신 기말 값 | 첫 연도처럼 평균을 못 내 기말 값만 쓴 비율은 숫자 뒤에 `†`를 붙이고 표 아래에 "† 평균 대신 기말 값 기준"을 표시 | 15.4%† |

- 이유 문구("적자", "전기 자료 없음" 등)는 백엔드 계산 결과가 주는 문구를 그대로 쓰고, 프론트가 새로 만들지 않는다.
- 이자비용 대신 금융비용으로 계산한 경우, 이자보상배율 이름을 "이자보상배율(금융비용 기준)"으로 표시하고 외환·파생상품 손실이 포함될 수 있다는 안내를 붙인다.

## 2. 기능별 동작

### F1. 기업 검색·선택

| 구분 | 내용 |
| --- | --- |
| 입력 | 기업명 (일부만 입력해도 됨, 예: "삼성전") |
| 동작 | 입력값이 포함된 **상장기업**을 찾아 목록으로 보여준다 (최대 10개) |
| 목록에 보이는 것 | 기업명, 종목코드, 업종 |
| 결과 | 기업 하나를 누르면 F2 경쟁사 선택으로 넘어간다 |

조건과 예외
- 2글자 미만이면 검색하지 않고 "2글자 이상 입력해 주세요" 안내
- 기업명에 "스팩" 또는 "기업인수목적"이 들어간 기업(기업인수목적회사)은 검색 결과에서 뺀다
- 정렬: 이름이 검색어와 같은 기업 → 검색어로 시작하는 기업 → 검색어를 포함하는 기업 순이고, 같은 순위 안에서는 이름이 짧은 순(대표 기업이 앞에 오도록), 그다음 가나다순
- 상장 일반 결과가 10개를 넘으면 앞의 10개만 보여주고 "결과가 많습니다. 더 정확한 이름으로 검색해 주세요" 안내
- 검색 결과가 없으면 "상장기업 중 일치하는 기업이 없습니다" 안내 (비상장기업도 이 안내)
- 금융업(은행·증권·보험 등 업종코드)이면 목록에는 보이되 선택 시 "현재 버전은 일반기업만 분석합니다" 안내 후 진행하지 않음

### F2. 경쟁사 선택

| 구분 | 내용 |
| --- | --- |
| 입력 | F1에서 고른 기업 |
| 동작 | 같은 업종코드의 상장 일반기업을 **최대 8곳** 후보로 보여준다 (매출 규모가 비슷한 순) |
| 사용자 행동 | 후보 중 선택·해제, 또는 기업명으로 검색해 직접 추가 |
| 조건 | **1~4곳**만 선택 가능. 5번째를 고르면 "최대 4곳까지 선택할 수 있습니다" |
| 결과 | [리포트 만들기]를 누르면 F3 시작 |

조건과 예외
- 후보가 하나도 없으면 "같은 업종 기업을 찾지 못했습니다. 직접 추가해 주세요" 안내
- 0곳 선택 상태에서는 [리포트 만들기] 버튼 비활성
- 금융업 기업은 직접 추가할 수 없음

### F3. 리포트 생성

| 구분 | 내용 |
| --- | --- |
| 입력 | 분석 기업 1곳 + 경쟁사 1~4곳 |
| 동작 | 아래 단계를 순서대로 진행하며 화면에 진행 상태를 보여준다 |
| 결과 | 완료되면 리포트를 **새 리포트로 자동 저장**하고 F4 리포트 보기로 이동 |

진행 단계

| 단계 | 하는 일 | 방식 |
| --- | --- | --- |
| 1. 재무 수집 | 분석 기업·경쟁사의 5년 재무제표 수집, 분석 기업의 최근 반기/3분기 보고서 손익 수집 | 코드 |
| 2. 공시 확인 | 공시 목록, 감사의견, 사업부문·수출 비중, 직원 현황, 연구개발비 확인 | 코드 + AI 추출 |
| 3. 기사 수집 | 최근 3개월 기사 최대 30건 수집 | 코드 |
| 4. 지표 수집 | 환율·기준금리 최근 1년, 주가 1년 시세·시가총액 | 코드 |
| 5. 계산 | 재무비율, 듀퐁, 현금흐름 패턴, PER·PBR, 신호등, 경쟁사 비교(시가총액 순위 포함), 주가 지수화(1년 전 = 100), 연구개발비 비중 | 코드 |
| 6. 해석 작성 | 섹션별 한 줄 요약, 주석, PEST, 5 Forces, BCG, 기사 묶음, 민감도, SWOT, 종합 평가, 과제·기여 제안(SWOT까지 만든 뒤 마지막) | AI |

조건과 예외
- 상장 5년 미만: 있는 연도만으로 계산하고, 리포트에 "N년 자료만 있음" 표시
- 기사가 0건: 기사 섹션에 "최근 3개월 기사 없음", 나머지는 정상 생성
- 한 단계가 실패하면 **어느 단계에서 실패했는지** 보여주고 [다시 시도] 버튼 제공. 실패한 리포트는 저장하지 않음
- 경쟁사 중 일부의 데이터가 없으면 그 회사만 비교표에서 빼고 "데이터 부족으로 제외" 표시

### F4. 리포트 보기

| 구분 | 내용 |
| --- | --- |
| 입력 | 저장된 리포트 1건 |
| 동작 | 4페이지를 순서대로 보여준다 (한 화면에서 스크롤, 페이지 구분선) |
| 상단 표시 | 기업명, 생성일, 기준 사업연도, 데이터 기준일, 연결/별도 구분 |

섹션 구성과 내용 (각 섹션 공통: 맨 위 한 줄 요약, 맨 아래 내 코멘트란)

**1페이지 — 한눈에 보기**

| 섹션 | 내용 | 표시 |
| --- | --- | --- |
| 기업 개요 | 업종, 주력 사업 설명 2~3문장 | 텍스트 (AI 작성) |
| 기업 개요 보조 지표 | 직원 수, 평균 근속연수, 평균 급여(최근 사업연도), 연구개발비와 매출 대비 비중 | 숫자 항목 (직원 현황은 코드, 연구개발비는 "AI 추출" 표시 + 원문 링크). 값이 없으면 "자료 없음" |
| 핵심 지표 카드 | 매출 성장률, 영업이익률, 부채비율, 영업현금흐름 | 카드 4개 + 전년 대비 화살표 + 신호등 |
| 종합 평가 | 한 줄 평가 + SWOT 4칸 | 텍스트 + 4칸 표 (AI 작성) |
| 업계 내 위치 | "비교한 5개 지표 중 3개 우위(…), 2개 열위(…)" 형태 한 줄 (평균 대비 기준) | 텍스트 |
| 사업부문 비중 | 부문별 매출 비중 | 막대 또는 도넛 차트 |

**2페이지 — 재무 건전성과 회계 이슈**

| 섹션 | 내용 | 표시 |
| --- | --- | --- |

## 3. 계산 기준

### 5대 재무비율

| 그룹 | 지표 | 계산식 |
| --- | --- | --- |
| 수익성 | 영업이익률 | 영업이익 ÷ 매출액 |
| | 순이익률 | 당기순이익 ÷ 매출액 |
| | ROE | 지배주주 순이익 ÷ 평균 지배주주 자본 |
| | ROA | 당기순이익 ÷ 평균 총자산 |
| 안정성 | 부채비율 | 부채총계 ÷ 자본총계 |
| | 유동비율 | 유동자산 ÷ 유동부채 |
| | 이자보상배율 | 영업이익 ÷ 이자비용 |
| 활동성 | 총자산회전율 | 매출액 ÷ 평균 총자산 |
| | 매출채권회전율 | 매출액 ÷ 평균 매출채권 |
| | 재고자산회전율 | 매출원가 ÷ 평균 재고자산 |
| 성장성 | 매출액증가율 | (당기 매출 − 전기 매출) ÷ 전기 매출 |
| | 영업이익증가율 | (당기 영업이익 − 전기 영업이익) ÷ 전기 영업이익의 절댓값 |
| | 총자산증가율 | (당기 총자산 − 전기 총자산) ÷ 전기 총자산 |
| 시장가치 | PER | 시가총액 ÷ 지배주주 순이익 |
| | PBR | 시가총액 ÷ 지배주주 자본 |

- "평균"은 (기초 + 기말) ÷ 2. 첫 연도는 기말 값만 사용하고 표시
- 분모가 0이거나 음수여서 의미 없는 경우(예: 적자일 때 PER) 숫자 대신 "해당 없음(적자)" 표시
- 시가총액은 리포트 생성 시점의 가장 최근 거래일 기준

### 듀퐁 분석

ROE = 순이익률 × 총자산회전율 × 재무레버리지(평균 총자산 ÷ 평균 자본)
- 세 요소 중 전년 대비 가장 크게 변한 요소를 "ROE가 변한 주된 이유"로 표시

| 지표 | 양호 | 주의 | 위험 |

| 부채비율 | 전년보다 같거나 낮음 | 전년보다 50%p 이내 상승 | 50%p 넘게 상승 또는 200% 초과 |

### 경쟁사 비교

- 지표 7개: 매출액, 매출액증가율, 영업이익률, ROE, 부채비율, PER·PBR, 시가총액 (최근 사업연도, 시가총액은 리포트 생성 시점 기준)
- **단계 구분**: Phase 5-A는 DART 재무 5개 지표(매출액, 매출액증가율, 영업이익률, ROE, 부채비율), Phase 5-B(주식시세 키 활성화 후)에서 PER·PBR·시가총액 열을 추가한다. 열은 지표 정의 목록에서 만들어지므로 5-B는 정의를 추가하는 방식이다
- 기준 연도: 분석 기업의 기준 사업연도. 그 연도 자료나 매출액이 없는 경쟁사는 "데이터 부족으로 제외". 연결/별도는 기업마다 다를 수 있어 표에 기업별로 표시
- 순위 규칙(5-A 확정): 값이 같으면 같은 순위(1, 1, 3), 해당 없음·자료 없음은 순위와 평균에서 제외, 비교 가능한 기업이 2곳 미만이면 순위 없음. 평균은 분석 기업을 포함한 단순 평균
- **업계 내 위치 한 줄은 평균 대비 기준(표의 ▲▼와 같은 기준)**: 지표마다 분석 기업 값을 평균(분석 기업 포함)과 비교해 "우위"(부채비율은 평균보다 낮을 때, 나머지는 평균보다 높을 때) / "열위"(그 반대) / "평균 수준"(평균과 같을 때)으로 나눈다. 문장 예: "SK하이닉스: 비교한 5개 지표 중 3개 우위(…), 2개 열위(…)." 순위는 표에만 두고 문장에는 쓰지 않는다 (숫자는 코드가 센다)
- 각 지표에 **분석 기업 + 경쟁사 평균** 대비 ▲▼와 순위 표시 (1위 = 가장 좋음, 부채비율은 낮을수록 1위)
- PER·PBR은 높고 낮음에 좋고 나쁨이 없으므로 순위 없이 "평균 대비 높음·낮음"만 표시
- 시가총액은 경쟁사 중 순위를 표시한다. 큰 쪽이 1위이고, 규모 순위이지 좋고 나쁨이 아님
- 점 그래프: 가로 매출액증가율, 세로 영업이익률, 분석 기업은 다른 색
- 주가 흐름 선 차트: 기업마다 (날짜별 종가 ÷ 1년 전 기준일 종가) × 100. 기준일은 리포트 생성일 1년 전 날짜 이후 첫 거래일. 분석 기업은 다른 색. 수정주가가 아니라서 차트 아래에 한계를 표시 (6장 확인 필요 4)
- 업계 내 위치 한 줄: 평균 대비로 "우위/열위/평균 수준" 문장 구성 (순위 기준 아님)

### 최근 실적 박스

- **어느 보고서인가**: 5년 추이의 마지막 사업연도(N) 다음 해(N+1)의 반기 또는 3분기 보고서. 3분기가 있으면 3분기, 없으면 반기. 해당 기간이 아직 끝나지 않았거나(반기는 6월 말, 3분기는 9월 말 이후부터) 보고서가 제출되지 않았으면 박스를 생략하고 "아직 제출된 반기·3분기 보고서가 없습니다"를 표시 (1분기와 이미 사업보고서에 포함된 연도의 보고서는 쓰지 않음)
- **누적 기준**: 반기는 1~6월, 3분기는 1~9월 누적 값을 전년 같은 기간 누적 값과 비교한다 (3개월 값이 아니라 누적). 화면에 기간을 함께 표시한다. 12월 결산 기업을 가정한다 (6장 확인 필요 6)
- **항목**: 매출액, 영업이익, 영업이익률(영업이익 ÷ 매출액), 지배주주 순이익
- **증감**: 매출액·영업이익·지배주주 순이익은 증감률 = (당기 누적 − 전년 동기 누적) ÷ |전년 동기 누적|. 영업이익률은 %p 차이. 분모가 0이면 "해당 없음"
- **기준**: 5년 추이와 같은 연결/별도 기준 (별도면 지배주주 순이익은 당기순이익으로 대신하고 표시)
- **넣지 않는 것**: ROE·회전율처럼 1년 기준으로 읽는 지표, 누적이 아닌 3개월 값
- 단위는 억 원, 출처는 해당 보고서 접수번호와 원문 링크

### 기업 개요 보조 지표

- 연구개발비 비중 = 연구개발비 ÷ 매출액 (최근 사업연도, 비율은 소수점 첫째 자리 %)
- 연구개발비 금액은 사업보고서에서 AI가 추출한 값이므로 "AI 추출" 표시 + 원문 링크를 붙이고, 비중은 코드가 계산한다
- 연구개발비 기재가 없거나 매출액이 0이면 "자료 없음"으로 표시한다
- 직원 수·평균 근속연수·평균 급여는 DART 값을 그대로 보여주고 계산하지 않는다. 사업보고서 기준(보통 별도 법인)임을 값 옆에 표시한다

### 경제 환경 민감도

- 수출 비중(사업보고서에서 추출)과 환율 1년 추이를 함께 보여준다
- "환율 10% 상승 시" 영향은 **방향과 이유만** 쓴다 (예: "수출 비중 70%로 매출에는 긍정적, 원재료 수입이 많아 원가에는 부정적"). 금액 추정은 하지 않는다

## 6. 확인 필요 (개발 준비 단계에서 확인)

1. **주가·시가총액 출처**: 공공데이터포털 금융위원회 주식시세정보(무료, 공식)를 1순위로 쓰고, 키 발급 후 시가총액 항목 제공 여부 확인
2. **API 사용 조건**: 각 API의 일일 호출 한도를 키 발급 시 확인. 네이버는 NAVER API HUB로 이전을 마쳤고(새 키 발급됨), 유료 전환 여부는 콘솔에서 확인. 에러 응답 형식이 예전과 달라 분류를 실호출 결과로 맞추는 중 (`backend/check_keys.py`)
3. **AI 사용량**: 리포트 1건당 AI(LLM) 사용량·비용을 첫 리포트 생성 후 측정. 공유 키라 한도를 직접 걸 수 없을 수 있으므로 0장 규칙 9로 사용을 제한
4. **1년 주가 시계열** (키 발급 후 확인): 금융위원회 주식시세정보에서 기업별 최근 1년 일별 시세(종가)를 기간으로 조회할 수 있는지, 분석 기업+경쟁사 최대 5곳 호출 수가 일일 한도 안인지 확인. 1년 전 날짜가 휴장일이면 다음 첫 거래일 사용(제안). 수정주가가 아닌 한계는 확인 결과와 상관없이 차트 아래에 표시하기로 결정함 (5장)
5. **(새로 생김) OpenAI 공유 키**: 부서 공유 키를 쓰는 것에 대한 사용 허락, 사용 가능한 모델·한도를 Phase 6 시작 전에 확인. 사용할 모델은 Phase 6에서 정한다
6. **(새로 생김) 최근 실적 박스**: 비12월 결산 기업은 기간 표시(예: 01~06)가 맞지 않을 수 있어 12월 결산을 가정함. 3분기 보고서 제출 직후·사업보고서 제출 직전 등 경계 시기에 박스를 생략하는 규칙이 맞는지 써보며 확인
